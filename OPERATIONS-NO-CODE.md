# Gestione senza programmare

## Aggiornare i dati

L'aggiornamento parte automaticamente ogni notte.

Per avviarlo subito da GitHub:

1. apri la scheda **Actions** del repository;
2. scegli **Aggiorna dati Camera**;
3. premi **Run workflow**;
4. attendi il segno di spunta verde.

Se i dati cambiano, GitHub aggiorna il file pubblico e ripubblica il sito automaticamente.

## Correggere una scheda

1. apri **Issues**;
2. scegli **Correzione dati**;
3. compila il modulo con il link alla fonte ufficiale;
4. invia.

La segnalazione non modifica subito il punteggio: resta visibile e verificabile finché un maintainer non approva la correzione.

## Pubblicare una nuova versione

Ogni modifica approvata sul ramo `main` pubblica automaticamente il sito. Non è necessario caricare file a mano.

## Cambiare la formula

Non modificare direttamente i numeri. Apri una issue “Proposta metodologia”: il confronto pubblico impedisce cambi opachi o favorevoli a una parte politica.
