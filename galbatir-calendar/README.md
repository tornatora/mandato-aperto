# GAL BaTiR — Calendario eventi

Dashboard operativa per individuare date libere e conflitti tra eventi pubblici nella provincia di Reggio Calabria.

## Funzioni
- calendario mensile con stato libero / bassa pressione / occupato / copertura incompleta
- filtri per all'aperto, luogo chiuso, sagre e fiere, religioso, sport
- dettaglio giornaliero con luogo, categoria e fonte
- classifica automatica delle date migliori
- verifica server-side della raggiungibilità delle fonti pubbliche
- date GAL salvabili localmente
- responsive desktop/mobile
